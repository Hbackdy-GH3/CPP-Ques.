# C++ Practice

My personal C++ practice repo. Every program here is written by me while learning C++,
then reviewed and fixed until it gives correct output.

## What's inside
Practice programs grouped by what they practise:

- **Basics** – loops, functions, input validation, number problems
- **Strings** – parsing sentences, counting, searching, formatting text
- **OOP** – classes, constructors, encapsulation, inheritance, polymorphism,
  abstract classes, operator overloading, friend functions, Rule of 3
- **STL** – vector, set, map, unordered_map, stack, queue, priority_queue,
  sort, lambdas, lower_bound / upper_bound
- **Mini projects** – small menu-driven programs that combine the above
  (bank account, library system, hospital queue, games)

Each file is a single, self-contained program with its own `main()`.

## How to run
g++ -std=c++17 program_name.cpp -o app
./app

Or paste the file into any online C++ compiler.

## Learning path
C → C++ basics → OOP → STL → DSA (LeetCode / Striver A2Z)

## Notes
- Programs are kept simple on purpose; the goal is practice, not production code.
- Mistakes I made and fixed are part of the learning — check the commit history.
